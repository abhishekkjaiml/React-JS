# 🍿 About The Project

**Movie App** is a modern and responsive movie discovery application created to make exploring movies simple, fast, and enjoyable.

The application connects with the **OMDb API** to retrieve movie information and presents it through a clean, responsive, and visually focused interface.

The project was built as a practical React.js project to strengthen my understanding of:

```text
React.js
   ↓
Components
   ↓
State Management
   ↓
API Integration
   ↓
Dynamic Rendering
   ↓
Responsive UI
   ↓
Production Build
```

# ⚙️ Getting Started

## 📋 Requirements

Before running the project, make sure you have:

- Node.js installed
- npm installed
- Git installed
- A modern web browser
- OMDb API key

---

## 1️⃣ Clone

```bash
git clone https://github.com/abhishekkjaiml/React-JS.git
```

---

## 2️⃣ Enter Project

```bash
cd React-JS/react-movie-app
```

---

## 3️⃣ Install Packages

```bash
npm install
```

---

## 4️⃣ Configure API Key

Create a `.env` file:

```env
VITE_API_KEY=your_omdb_api_key
```

---

## 5️⃣ Start Application

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
