## 📖 Overview

**NoteIt** is a modern and responsive note-taking web application built using **React.js** and **Vite**.

The application is designed to provide a simple and intuitive experience for creating, managing, and organizing notes. It follows a **component-based architecture** with reusable React components and modern frontend development practices.

The project focuses on creating a clean user interface, efficient state management, responsive layouts, and a smooth user experience.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js v18+
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/abhishekkjaiml/note-app.git
```

### 2. Navigate to the Project

```bash
cd note-app
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## 🔐 Environment Variables

Create a `.env` file in the project root if environment variables are required.

Example:

```env
VITE_API_URL=
VITE_API_KEY=
VITE_APP_NAME=NoteIt
```

> ⚠️ Never commit your `.env` file if it contains private credentials.  
> The `.env` file is ignored by Git, while `.env.example` can be committed safely.
